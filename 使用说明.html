物业管理台账 · 使用说明

HTML 单文件版 v1.2 · 双击即用 · 数据 100% 存在本机 · 兼容 PC / 平板 / 手机

快速开始数据存在哪备份与恢复 功能清单常见问题

1快速开始

1
用 Chrome 或 Edge 浏览器打开 index.html：双击文件即可，无需安装任何软件、无需联网。
2
使用默认总管理员账号登录：
登录名 admin　密码 admin123
3
登录后请立即到「设置 → 修改密码」改掉默认密码，再到「设置 → 账单基础信息」填写房东称呼、收款提示语，并上传收款码。
4
开始录入业务数据，推荐顺序：物业 → 房间 → 租客 → 租约。签订租约并保存后，系统会按「月付 / 季付」自动生成账单。
💡 建议保持文件位置固定：浏览器的本地数据与「文件的打开位置」相关联。建议把两个文件放在一个固定文件夹里长期使用，不要频繁改名或移动，否则浏览器可能视为新文件、看不到之前的数据（数据并未丢失，把文件放回原路径即可）。

2数据存在哪里？

所有数据（物业、房间、租客、租约、账单、收款、经验、账号、收款码）都保存在当前浏览器、当前电脑的 IndexedDB 本地数据库里：

  • 不上传服务器、不联网，断网也能正常使用；
  • 同一台电脑的 Chrome 和 Edge 是两套独立数据，请固定用同一个浏览器；
  • 浏览器的「无痕 / InPrivate 模式」关闭后数据即清空，不要在无痕模式下使用；
  • 账号密码采用 PBKDF2 加密存储，登录状态关闭标签页后失效，每次打开需重新登录。
⚠️ 重要：清理浏览器数据（Cookie 及网站数据 / 站点数据）会把台账数据一并清掉！清缓存时请选择「仅缓存的图片和文件」，并在清理前先做一次 JSON 导出备份。
✅ 推荐一劳永逸的做法：在「设置 → 独立数据库文件」中选择一个 .sqlite 文件（电脑版 Chrome / Edge 支持），之后每笔改动都会自动写入这个文件（默认名 物业台账.sqlite），清缓存也不怕——重新打开页面点「授权并读取」即可完整恢复。这个 .sqlite 文件就是你的独立数据库文件，备份时只需把 HTML + .sqlite 两个文件一起拷走。

3备份与恢复（重点）

🗄️ 方式一（推荐）：独立数据库文件（.sqlite），自动保存、防清缓存

💡 为什么这是首选：你会在电脑上得到一个真正的、看得见的独立数据库文件（物业台账.sqlite），就像原来 Blazor 版的 PostgreSQL 数据库文件一样。每笔改动自动写入它，清缓存不丢，换电脑拷走即用。
1
选择 / 创建数据库文件：设置 → 独立数据库文件 → 选择数据库文件（自动保存），浏览器弹出「另存为」对话框。建议文件名用 物业台账.sqlite（默认值），保存位置建议和 HTML 同一文件夹。
如果选了一个空文件或不存在的文件，系统会从零创建（首次保存会自动初始化）；
如果选了一个已有数据的 .sqlite 文件，系统会把它读入当前浏览器（覆盖 IndexedDB）。
2
之后自动运行：绑定完成后，你正常记账、收款、改设置……约 1 秒后自动写入 .sqlite 文件，不需要手动操作。
3
下次打开：浏览器会记住你绑定过的文件。如果缓存清过，登录框下方会出现「🗄️ 检测到已绑定的数据库文件」，点「授权并读取数据库文件」即可一键恢复——每次打开多点一下授权，这是浏览器安全设计，不是麻烦。
4
换电脑 / 换浏览器：把 物业管理台账.html + 物业台账.sqlite（+ 使用说明.html）三个文件一起拷过去，打开 HTML → 登录页会出现恢复提示 → 授权读取 → 数据全在。
💡 文件扩展名说明：文件可以叫 .sqlite、.db 或 .json——内容是结构化 JSON，不是二进制 SQLite，但概念上就是「独立数据库文件」。你可以用任意文本编辑器打开查看，也可以用 JSON 格式化工具美化。

📤 方式二：手动导出 JSON

路径：设置 → 数据备份与恢复 → 导出全部数据。会得到一个 物业管理台账备份-日期.json 文件，内含全部数据与账号。建议每次有重要录入后导出一次，和 HTML 文件放在同一文件夹或网盘保存。

📥 恢复 / 搬家：导入 JSON

路径：设置 → 数据备份与恢复 → 从备份恢复。选择之前导出的 JSON 文件并确认即可。导入会清空并覆盖当前全部数据（含账号密码），操作前请确认。

换电脑 / 换浏览器的标准流程

1
旧环境：导出 JSON 备份；
2
把 两个 HTML 文件 + 备份 JSON 一起拷到新电脑（U 盘 / 微信传输 / 网盘均可）；
3
新电脑用 Chrome/Edge 打开 物业管理台账.html，用默认账号 admin / admin123 登录；
4
执行「从备份恢复」导入 JSON —— 数据、账号、收款码全部还原，之后正常改密使用。
💡 已绑定数据文件的更快做法：换电脑时把两个 HTML + 数据 JSON 拷过去，打开页面后直接点登录框下方的「授权并读取数据文件」即可，无需导入。
💡 两个文件的分工：「物业管理台账.html」是软件本体，里面不含数据，可随意替换为新版本；「备份 JSON / 数据 JSON」才是你的数据。备份时请都留着。

📱 手机 / 平板上使用

  • 界面自适应：桌面为侧边栏，窄屏自动切换为底部导航 + 卡片式列表，触控友好；
  • 安卓：可用 Chrome / Edge 移动版打开本地文件（文件管理器 → 用浏览器打开，或浏览器地址栏输入 file:///sdcard/路径/物业管理台账.html）；
  • iPad / iPhone：可通过「文件」App 分享到 Safari 打开；iOS 对浏览器本地存储有限制，数据易丢失，务必定期导出 JSON 备份；
  • 数据跟随「浏览器 + 设备」，手机上录入的数据不会自动出现在电脑上——用导出 / 导入 JSON 同步。

📱 手机端完整备份方案（方式一在手机上不可用）

⚠️ 说明：手机 / 平板浏览器（安卓 Chrome、iOS Safari 等）不支持「数据文件绑定」功能（该功能依赖电脑版 Chrome / Edge 的 File System Access API），手机上只能走「导出 JSON → 传输 → 导入」的方式。请按以下流程操作。

安卓手机（Chrome / Edge 移动版）

1
导出：登录后进入「设置 → 数据备份与恢复 → 导出全部数据」，浏览器会触发下载。下载的 JSON 文件通常在「下载」文件夹（可在浏览器地址栏输入 chrome://downloads 查看）。
2
传到电脑：几种方式任选：
• 微信「文件传输助手」发送（手机选文件 → 微信 → 电脑端接收）；
• 腾讯文档 / 百度网盘 / OneDrive 等云盘上传；
• USB 数据线连电脑，在「此电脑\手机名\内部存储\Download」里拷出。
3
电脑端导入：电脑上打开 物业管理台账.html → 登录 → 设置 → 从备份恢复 → 选择这个 JSON 文件。

iPhone / iPad（Safari / Chrome）

1
导出：登录后进入「设置 → 数据备份与恢复 → 导出全部数据」。Safari 会弹出分享面板，选「存储到『文件』」或「存储到『下载』」——JSON 会出现在「文件」App 里。
2
传到电脑：几种方式任选：
• 微信「文件传输助手」发送（文件 App → 选中 JSON → 分享 → 微信）；
• iCloud Drive（文件 App 自动同步），电脑上「访达」或「此电脑\iCloud Drive」取；
• AirDrop 直接发给附近的 Mac；
• 云盘 App 上传。
3
电脑端导入：同安卓，电脑上从备份恢复。

定期备份建议

  • iOS 用户尤其注意：iOS Safari 在磁盘空间紧张时可能自动清理浏览器本地存储（IndexedDB 一并清掉），每次有重要录入后请立即导出，不要等；
  • 安卓 Chrome / Edge 相对稳定，但清浏览器数据 / 卸载重装 / 切换浏览器都会丢数据，同样建议定期导出；
  • 导出的 JSON 建议和两个 HTML 文件放在同一个云盘文件夹里，电脑端也能直接取用。

5常见问题

打开后一直空白或提示「数据库初始化失败」？

请改用 Chrome / Edge 较新版本打开；部分老旧浏览器或兼容模式不支持 IndexedDB。IE 浏览器不支持。

之前录的数据怎么不见了？

按顺序排查：① 是否换了浏览器（Chrome 和 Edge 数据独立）；② 文件是否被移动 / 改名后放在新路径打开（放回原路径即可找回）；③ 是否用了无痕模式；④ 是否清理过浏览器站点数据——若已绑定 .sqlite 数据库文件，重新打开页面点「授权并读取数据库文件」即可完整恢复；若未绑定且无备份则无法找回，请立即按「方式一」绑定数据库文件。

.sqlite 文件为什么可以直接双击打开？

.sqlite 是你给它起的扩展名，内容其实是结构化 JSON 文本（类似 .json 文件）。双击会用系统默认的文本编辑器打开，你能看到全部数据。真正的 SQLite 数据库文件是二进制格式，双击会乱码——但我们用 JSON 格式反而更友好：可查看、可 diff、可用 Git 跟踪、可任意文本编辑器处理。叫 .sqlite 是为了和「数据库文件」的概念对齐，方便你一眼认出它。

忘了 admin 密码怎么办？

若其他普通用户能登录且被分配了「设置」权限，可由其在设置中操作；否则只能在导入旧备份（密码尚未修改时的备份）或清空浏览器站点数据后用默认 admin / admin123 重新开始——所以请务必保管好密码并定期导出备份。

季付租约的账单是怎么生成的？

以起租月为基准，每 3 个月出一张账单，账期为连续 3 个自然月，金额 = 账单跨入的 3 个月各自月租之和（未设置租金递增时即 月租金 × 3）；到期日 = 账期首月的付租日。例如 3 月 5 日起租、季付：出账月份为 3、6、9、12 月……设置了租金递增的租约，出账金额按「起租后第几个租约年」自动套用递增后的月租（已生成的历史账单金额不变）。

想给某个月免租怎么操作？

打开该月账单 → 编辑租金改为 0（应收即变为杂费合计）。直接删掉自动生成的账单，下次打开账单页时会按租约标准重新生成，所以免租请改租金为 0 而不是删单。

两个 HTML 文件可以在手机和电脑间直接同步数据吗？

不能自动同步。HTML 文件只是软件本体，数据在浏览器里；跨设备请用「导出 JSON → 传输 → 导入」三步走。
